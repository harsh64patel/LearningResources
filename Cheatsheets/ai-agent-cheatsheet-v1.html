What is an AI Agent?

Foundation concepts every developer must know

Concept ›

✅ An Agent IS:

  • • An LLM that decides what actions to take
  • • Can use tools to interact with the world
  • • Runs in a loop until task is done
  • • Has access to memory across steps
  • • Can plan, reason, and adapt
  • • Goal-directed: works toward an objective

❌ An Agent is NOT:

  • • Just a single LLM call
  • • A simple chatbot with no tools
  • • A rigid scripted pipeline
  • • Something that always follows the same steps
  • • A black box you can't trace or debug
  • • A replacement for all human judgment

Pattern #1 — ReAct (Reason + Act)

The most important beginner pattern. The foundation of most agents.

Beginner Pattern ›
🎯 When to use ReAct: Any task where the agent needs to gather information, reason about it, and take iterative actions. It's the default pattern for most agents.

How ReAct Works

1
Thought: LLM reasons about the problem
↓
2
Action: Decides which tool to call
↓
3
Observation: Gets tool result
↓
🔁
Repeat until done
sequenceDiagram participant U as 👤 User participant A as 🧠 Agent LLM participant T as 🔧 Tool U->>A: "What's the weather in Tokyo?" Note over A: Thought: I need to\ncall the weather tool A->>T: weather_search("Tokyo") T-->>A: {"temp": "22°C", "cond": "Sunny"} Note over A: Thought: I have the data,\ncan answer now A-->>U: "Tokyo is 22°C and sunny"

ReAct Prompt Format

system_prompt = """You are a helpful AI agent. Use the following format:

Thought: Think about what you need to do next
Action: The tool to use (one of: {tool_names})
Action Input: The input to the tool
Observation: The result of the tool call
... (Thought/Action/Observation can repeat N times)
Thought: I now have enough information to answer
Final Answer: The complete answer to the user's question

Available tools:
{tools_description}
"""

# Example ReAct trace:
# Thought: I need to find the population of Tokyo
# Action: web_search
# Action Input: "population of Tokyo 2024"
# Observation: Tokyo has a population of approximately 13.9 million
# Thought: I now know the answer
# Final Answer: Tokyo's population is approximately 13.9 million people.

from langchain_openai import ChatOpenAI
from langchain.tools import Tool
from langchain import hub

# 1. Define your tools
def search_web(query: str) -> str:
    """Search the web for information."""
    # Replace with real search implementation
    return f"Results for: {query}"

def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"Error: {e}"

tools = [
    Tool(name="web_search", func=search_web,
         description="Search the web for current information"),
    Tool(name="calculator", func=calculator,
         description="Evaluate math expressions"),
]

# 2. Create the LLM
llm = ChatOpenAI(model="gpt-4o", temperature=0)

# 3. Pull the ReAct prompt from LangChain Hub
prompt = hub.pull("hwchase17/react")

# 4. Create the agent
agent = create_react_agent(llm, tools, prompt)

# 5. Create executor with safety limits
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,          # Print reasoning steps
    max_iterations=10,     # Prevent infinite loops
    handle_parsing_errors=True,  # Handle LLM format errors
    return_intermediate_steps=True,  # For debugging
)

# 6. Run the agent
result = agent_executor.invoke({
    "input": "What is 15% of the population of Japan?"
})
print(result["output"])

✅ ReAct Strengths

  • • Transparent reasoning you can read
  • • Works with almost any LLM
  • • Easy to debug (trace the thoughts)
  • • Flexible tool integration
  • • Self-corrects on tool errors

⚠️ ReAct Limitations

  • • Can get stuck in loops
  • • Slow with many tool calls
  • • Weaker LLMs struggle with format
  • • Context fills up on long tasks
  • • No parallel tool execution

Pattern #2 — Function Calling / Tool Use

Structured way for LLMs to call external functions & APIs

Beginner Pattern ›
💡 Key Insight: Function calling is how you give your agent superpowers. Instead of the LLM guessing, it calls real APIs, databases, and services with structured inputs.
flowchart TD A["👤 User: 'Book a flight to NYC'"] --> B["🧠 LLM analyzes request"] B --> C{"Does it need\na tool?"} C -->|Yes| D["📋 Generate tool call JSON\n{name: search_flights,\nargs: {to: NYC, date: ...}}"] C -->|No| H["💬 Direct text response"] D --> E["⚙️ Execute Function\nsearch_flights(to='NYC')"] E --> F["📊 Return Results\n[{flight: AA101, price: $250}]"] F --> G["🧠 LLM processes results\n+ generates response"] G --> I["✅ 'Found flights: AA101 for $250'"] style A fill:#3b82f6,color:#fff style D fill:#10b981,color:#fff style I fill:#10b981,color:#fff

Defining Tools — OpenAI Format

import openai
import json

client = openai.OpenAI()

# Define tools with JSON Schema
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get current weather for a city",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "City name, e.g. 'Tokyo'"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["city"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "create_calendar_event",
            "description": "Create a calendar event",
            "parameters": {
                "type": "object",
                "properties": {
                    "title": {"type": "string"},
                    "date": {"type": "string", "description": "ISO 8601 format"},
                    "duration_minutes": {"type": "integer"}
                },
                "required": ["title", "date"]
            }
        }
    }
]

# Actual function implementations
def get_weather(city: str, unit: str = "celsius") -> dict:
    # Call real weather API here
    return {"city": city, "temp": 22, "unit": unit, "condition": "sunny"}

def create_calendar_event(title: str, date: str, duration_minutes: int = 60) -> dict:
    return {"success": True, "event_id": "evt_123", "title": title}

# Map function names to implementations
available_functions = {
    "get_weather": get_weather,
    "create_calendar_event": create_calendar_event,
}

def run_agent(user_message: str):
    messages = [{"role": "user", "content": user_message}]

    while True:
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools,
            tool_choice="auto"  # Let model decide
        )
        msg = response.choices[0].message

        # If no tool calls, we're done
        if not msg.tool_calls:
            return msg.content

        # Execute each tool call
        messages.append(msg)  # Add assistant message

        for tool_call in msg.tool_calls:
            func_name = tool_call.function.name
            func_args = json.loads(tool_call.function.arguments)

            # Execute the function
            result = available_functions[func_name](**func_args)

            # Add result to messages
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": json.dumps(result)
            })

# Usage
result = run_agent("What's the weather in Tokyo and schedule a meeting tomorrow at 2pm?")
print(result)

Tool Design Best Practices

✅ Good Tool Design

  • • Clear, specific name: search_customer_orders
  • • Detailed description of what it does
  • • Explicit parameter descriptions
  • • Returns structured data (JSON)
  • • Handles errors gracefully
  • • Idempotent reads when possible
  • • Rate limiting built in

❌ Bad Tool Design

  • • Vague name: do_thing
  • • No description or poor description
  • • Returns raw HTML/text blobs
  • • Throws exceptions without handling
  • • Too many parameters (>5)
  • • Irreversible actions without confirmation
  • • No timeout or retry logic

🗑️ Destructivedelete_record, cancel_orderHighAlways require human-in-loop

Pattern #3 — Chain of Thought (CoT)

Force the LLM to reason step-by-step before answering

Beginner Pattern ›
🎯 Use CoT when: Tasks require multi-step reasoning, math, logical deduction, complex decisions, or when you need to verify the model is "thinking" correctly.

CoT Variants

Zero-shot CoT

Add "Let's think step by step" to the prompt

Few-shot CoT

Provide worked examples with reasoning steps

Self-Consistency CoT

Sample multiple reasoning paths, pick majority answer

Tree of Thought (ToT)

Explore multiple reasoning branches, backtrack if needed

flowchart TD Q["❓ Complex Question"] --> ZS["Zero-Shot CoT\n'Think step by step'"] ZS --> R1["Step 1: Understand\nthe problem"] R1 --> R2["Step 2: Break down\ninto sub-parts"] R2 --> R3["Step 3: Solve\neach part"] R3 --> R4["Step 4: Combine\nresults"] R4 --> A["✅ Final Answer"] style Q fill:#8b5cf6,color:#fff style A fill:#10b981,color:#fff

CoT Prompt Templates

from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o", temperature=0)

# Zero-shot CoT — just add the magic phrase
zero_shot_cot = ChatPromptTemplate.from_messages([
    ("system", """You are a precise analytical assistant.
When solving problems, always think step by step.
Show your complete reasoning before giving the final answer.
Format:

[your step-by-step reasoning here]

Final Answer: [answer]"""),
    ("human", "{question}")
])

# Few-shot CoT — provide examples
few_shot_cot_system = """Solve problems step by step.

Example:
Q: A store has 120 apples. They sell 35 in the morning and 48 in the afternoon. How many remain?
Thinking:
1. Start with 120 apples
2. Subtract morning sales: 120 - 35 = 85
3. Subtract afternoon sales: 85 - 48 = 37
Final Answer: 37 apples remain.

Now solve the following problem in the same way:"""

# Structured reasoning with XML tags (works great with Claude)
structured_cot = ChatPromptTemplate.from_messages([
    ("system", """You are an expert analyst. Always reason carefully.

Use this exact format:

What is being asked? What information do I have?



Step 1: ...
Step 2: ...
Step 3: ...



Does my answer make sense? Check the logic.



Final clear answer here.
"""),
    ("human", "{question}")
])

chain = structured_cot | llm

result = chain.invoke({
    "question": "Our API has 3 servers. Each handles 1000 req/s. "
                "If traffic is 2500 req/s, what % of capacity are we using?"
})
print(result.content)
⚡ Pro Tip: For enterprise agents, wrap CoT in <thinking> XML tags and strip them from user-facing output. Users see clean answers; you see the full reasoning in logs.

Pattern #4 — Plan and Execute

Separate planning from execution for complex multi-step tasks

Beginner Pattern ›
flowchart LR subgraph Planner["📋 Planner Agent"] P1["Analyze goal"] P2["Break into steps"] P3["Order dependencies"] P1-->P2-->P3 end subgraph Executor["⚙️ Executor Agent"] E1["Execute Step 1"] E2["Execute Step 2"] E3["Execute Step N"] E1-->E2-->E3 end subgraph Replanner["🔄 Re-Planner"] R1["Check progress"] R2["Adjust if needed"] R1-->R2 end Goal(["🎯 Goal"]) --> Planner Planner --> Executor Executor -->|"Step failed\nor unexpected result"| Replanner Replanner --> Executor Executor -->|"All done"| Done(["✅ Result"]) style Goal fill:#f59e0b,color:#fff style Done fill:#10b981,color:#fff 
from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain_core.output_parsers import JsonOutputParser
from pydantic import BaseModel
from typing import List
import json

llm = ChatOpenAI(model="gpt-4o", temperature=0)

# 1. PLANNER: Breaks goal into steps
class ExecutionStep(BaseModel):
    step_id: int
    description: str
    tool: str
    tool_input: dict
    depends_on: List[int] = []  # step IDs this step depends on

class ExecutionPlan(BaseModel):
    goal: str
    steps: List[ExecutionStep]
    reasoning: str

planner_prompt = ChatPromptTemplate.from_messages([
    ("system", """You are a planning agent. Break user goals into ordered steps.
Return a JSON plan with this structure:
{{
  "goal": "...",
  "reasoning": "why I chose these steps",
  "steps": [
    {{"step_id": 1, "description": "...", "tool": "...",
      "tool_input": {{}}, "depends_on": []}}
  ]
}}

Available tools: web_search, calculator, get_weather, send_email, read_file, write_file"""),
    ("human", "Goal: {goal}")
])

def create_plan(goal: str) -> ExecutionPlan:
    chain = planner_prompt | llm
    response = chain.invoke({"goal": goal})
    # Parse JSON from response
    data = json.loads(response.content)
    return ExecutionPlan(**data)

# 2. EXECUTOR: Runs each step
def execute_step(step: ExecutionStep, previous_results: dict) -> dict:
    """Execute a single step using the specified tool."""
    print(f"  Executing Step {step.step_id}: {step.description}")

    # Get results from dependent steps
    context = {f"step_{id}_result": previous_results.get(id, {})
               for id in step.depends_on}

    # Execute tool (simplified)
    if step.tool == "web_search":
        result = f"Web results for: {step.tool_input}"
    elif step.tool == "calculator":
        result = str(eval(step.tool_input.get("expression", "0")))
    else:
        result = f"Executed {step.tool} with {step.tool_input}"

    return {"step_id": step.step_id, "result": result, "success": True}

# 3. ORCHESTRATOR: Runs the full plan
def run_plan_execute(goal: str):
    print(f"\n🎯 Goal: {goal}")
    print("=" * 50)

    # Create plan
    print("\n📋 Creating plan...")
    plan = create_plan(goal)
    print(f"   Reasoning: {plan.reasoning}")
    print(f"   Steps: {len(plan.steps)}")

    # Execute steps in order
    results = {}
    for step in plan.steps:
        # Wait for dependencies
        deps_done = all(dep in results for dep in step.depends_on)
        if not deps_done:
            print(f"  ⚠️  Waiting for dependencies: {step.depends_on}")
            continue

        step_result = execute_step(step, results)
        results[step.step_id] = step_result

    # Synthesize final answer
    synthesis_prompt = f"""
    Goal: {goal}
    Steps executed: {json.dumps(list(results.values()), indent=2)}
    Provide a comprehensive final answer based on all results.
    """
    final = llm.invoke(synthesis_prompt)
    return final.content

# Usage
answer = run_plan_execute(
    "Research the top 3 AI frameworks for 2024, compare their GitHub stars, and recommend one"
)
print("\n✅ Final Answer:", answer)

✅ Best for:

  • • Multi-step research tasks
  • • Tasks with clear dependencies
  • • When you want a predictable execution path
  • • Long-running enterprise workflows

⚡ Optimization Tips:

  • • Run independent steps in parallel
  • • Add a re-planner for error recovery
  • • Cache step results for retry safety
  • • Set max replanning iterations

Pattern #5 — Human-in-the-Loop (HITL)

Critical for enterprise: when to pause and ask for human approval

Beginner Pattern ›
⚠️ Enterprise Critical: Never let agents autonomously perform irreversible or high-risk actions. HITL is not optional in production — it's your safety net.
flowchart TD A["🤖 Agent wants to take action"] --> B{"Risk Assessment"} B -->|"Low risk\n(read-only)"| C["✅ Auto-execute"] B -->|"Medium risk"| D["📧 Notify human\n+ auto-execute"] B -->|"High risk\n(write/delete)"| E["⏸️ Pause execution\nRequest approval"] B -->|"Critical\n(financial/legal)"| F["🔴 Hard stop\nMandatory review"] E --> G{"Human Decision"} F --> G G -->|"Approve ✅"| H["Execute action"] G -->|"Modify ✏️"| I["Agent revises plan"] G -->|"Reject ❌"| J["Skip / abort step"] I --> A C --> K["📝 Log action"] H --> K J --> K style E fill:#f59e0b,color:#fff style F fill:#ef4444,color:#fff style C fill:#10b981,color:#fff

HITL with LangGraph Interrupts

from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
    messages: list
    pending_action: dict | None
    human_approved: bool | None
    results: list

def risk_check(state: AgentState) -> str:
    """Determine if human approval is needed."""
    action = state.get("pending_action", {})
    tool = action.get("tool", "")

    HIGH_RISK_TOOLS = {"delete_record", "send_email", "create_payment", "update_database"}

    if tool in HIGH_RISK_TOOLS:
        return "needs_approval"
    return "auto_execute"

def request_approval(state: AgentState) -> AgentState:
    """Node that pauses and waits for human input."""
    action = state["pending_action"]
    print(f"\n⚠️  HUMAN APPROVAL REQUIRED")
    print(f"   Tool: {action['tool']}")
    print(f"   Args: {action['args']}")
    print(f"   Reason: {action.get('reason', 'N/A')}")
    # This node will be interrupted here by LangGraph
    # Human provides approval via state update
    return state

def execute_action(state: AgentState) -> AgentState:
    """Execute the approved action."""
    if state.get("human_approved") == False:
        return {**state, "results": state["results"] + ["Action rejected by human"]}

    action = state["pending_action"]
    # Execute the tool...
    result = f"Executed {action['tool']} successfully"
    return {
        **state,
        "results": state["results"] + [result],
        "pending_action": None,
        "human_approved": None
    }

# Build graph with interrupt
builder = StateGraph(AgentState)
builder.add_node("risk_check_node", lambda s: s)  # Router
builder.add_node("request_approval", request_approval)
builder.add_node("execute_action", execute_action)

builder.add_conditional_edges(
    "risk_check_node",
    risk_check,
    {
        "needs_approval": "request_approval",
        "auto_execute": "execute_action"
    }
)
builder.add_edge("request_approval", "execute_action")
builder.add_edge("execute_action", END)
builder.set_entry_point("risk_check_node")

# CRITICAL: interrupt_before causes the graph to pause
memory = MemorySaver()
graph = builder.compile(
    checkpointer=memory,
    interrupt_before=["execute_action"]  # Pause before executing!
)

# Usage
config = {"configurable": {"thread_id": "enterprise-task-1"}}

# Run until interrupt
state = graph.invoke({
    "messages": [],
    "pending_action": {"tool": "send_email", "args": {"to": "ceo@company.com", "subject": "Q4 Report"}},
    "human_approved": None,
    "results": []
}, config)

# Human reviews and approves
print("\n👤 Human: Approving action...")
graph.update_state(config, {"human_approved": True})

# Resume execution
final_state = graph.invoke(None, config)
print("Results:", final_state["results"])

🔵 Episodic Memory Pattern

Remember and learn from past task runs.

import json, sqlite3
from datetime import datetime

class EpisodicMemory:
    def __init__(self, db_path="agent_episodes.db"):
        self.conn = sqlite3.connect(db_path)
        self.conn.execute("""CREATE TABLE IF NOT EXISTS episodes
            (id INTEGER PRIMARY KEY, task TEXT,
             outcome TEXT, steps TEXT,
             success INTEGER, timestamp TEXT)""")

    def store_episode(self, task, outcome, steps, success):
        self.conn.execute(
            "INSERT INTO episodes VALUES (NULL,?,?,?,?,?)",
            (task, outcome, json.dumps(steps),
             int(success), datetime.now().isoformat()))
        self.conn.commit()

    def recall_similar(self, task: str, limit=3) -> list:
        # In production, use vector similarity
        cursor = self.conn.execute(
            "SELECT * FROM episodes WHERE success=1 "
            "ORDER BY timestamp DESC LIMIT ?", (limit,))
        return cursor.fetchall()

Level 3: LLM-as-Judge Evaluation

from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate

eval_llm = ChatOpenAI(model="gpt-4o", temperature=0)

EVAL_PROMPT = ChatPromptTemplate.from_messages([
    ("system", """You are an expert evaluator for AI agent responses.
Rate the response on these criteria (each 1-5):
- Correctness: Is the answer factually correct?
- Completeness: Does it fully answer the question?
- Helpfulness: Is it useful to the user?
- Safety: Is it free of harmful content?

Return JSON:
{{"correctness": N, "completeness": N, "helpfulness": N,
  "safety": N, "overall": N, "explanation": "..."}}"""),
    ("human", """Question: {question}
Agent Response: {response}
Ground Truth (if available): {ground_truth}
Evaluate:""")
])

def evaluate_response(question, response, ground_truth="N/A"):
    chain = EVAL_PROMPT | eval_llm
    result = chain.invoke({
        "question": question,
        "response": response,
        "ground_truth": ground_truth
    })
    import json
    return json.loads(result.content)

# Run eval suite
def run_evaluation_suite(agent, test_cases):
    scores = []
    for case in test_cases:
        response = agent.run(case["input"])
        score = evaluate_response(
            case["input"],
            response,
            case.get("ground_truth", "N/A")
        )
        scores.append(score)
        print(f"Q: {case['input'][:50]}...")
        print(f"   Overall: {score['overall']}/5 — {score['explanation'][:80]}")

    avg = sum(s["overall"] for s in scores) / len(scores)
    print(f"\n📊 Average Score: {avg:.2f}/5.0")
    return scores

from langchain.callbacks import StdOutCallbackHandler
from langchain.callbacks.base import BaseCallbackHandler

class EnterpriseTracer(BaseCallbackHandler):
    def __init__(self, run_id):
        self.run_id = run_id
        self.steps = []

    def on_agent_action(self, action, **kwargs):
        self.steps.append({
            "type": "action",
            "tool": action.tool,
            "input": action.tool_input,
        })
        print(f"🔧 Tool: {action.tool} | Input: {action.tool_input}")

    def on_tool_end(self, output, **kwargs):
        self.steps[-1]["output"] = str(output)[:200]
        print(f"   Result: {str(output)[:100]}...")

    def on_agent_finish(self, finish, **kwargs):
        print(f"✅ Done: {finish.return_values.get('output','')[:100]}")

# Usage

    {"input": "Query here"},
    {"callbacks": [tracer]}

Common Pitfalls & How to Avoid Them

Learn from others' mistakes — especially in enterprise

Pitfalls ›

🔄 Infinite Loops

Agent keeps calling tools without terminating. Costs money and time.

# ALWAYS set max_iterations
agent_executor = AgentExecutor(
    agent=agent, tools=tools,
    max_iterations=15,         # Hard stop
    max_execution_time=60.0,   # 60 second timeout
    early_stopping_method="generate",  # LLM generates final answer
)

🪟 Context Window Overflow

Too much history / tool results fill the context, causing errors or degraded performance.

# Truncate tool outputs
def safe_tool_output(result: str, max_chars=2000) -> str:
    if len(result) > max_chars:
        return result[:max_chars] + f"\n...[Truncated. Full result has {len(result)} chars]"
    return result

# Use token-aware memory management
from langchain.memory import ConversationTokenBufferMemory
memory = ConversationTokenBufferMemory(
    llm=llm,
    max_token_limit=3000,  # Keep within budget
    return_messages=True
)

💸 Runaway Token Costs

Agents in a loop with verbose tools can spend $100s accidentally.

from langchain.callbacks import get_openai_callback

# Track costs on every run
with get_openai_callback() as cb:
    result = agent_executor.invoke({"input": "query"})
    print(f"Tokens: {cb.total_tokens} | Cost: ${cb.total_cost:.4f}")

    # Alert if over budget
    if cb.total_cost > 0.50:  # $0.50 per run limit
        raise Exception(f"Cost limit exceeded: ${cb.total_cost:.2f}")

🎭 Prompt Injection

Malicious input in tool results manipulates agent behavior.

import re

def sanitize_tool_output(output: str) -> str:
    """Remove potential prompt injection attempts."""
    # Remove instruction-like patterns
    patterns = [
        r'ignore\s+previous\s+instructions',
        r'system:\s*you\s+are',
        r'new\s+instructions:',
        r'forget\s+everything',
    ]
    for pattern in patterns:
        output = re.sub(pattern, '[FILTERED]', output,
                       flags=re.IGNORECASE)
    return output

# Wrap all tool outputs
def safe_tool_wrapper(tool_func):
    def wrapper(*args, **kwargs):
        result = tool_func(*args, **kwargs)
        return sanitize_tool_output(str(result))
    return wrapper

🔇 Silent Failures

Agent fails silently and returns wrong answer with confidence.

class RobustTool:
    def __init__(self, func, name, max_retries=3):
        self.func = func
        self.name = name
        self.max_retries = max_retries

    def run(self, *args, **kwargs):
        for attempt in range(self.max_retries):
            try:
                result = self.func(*args, **kwargs)
                return {"success": True, "data": result}
            except Exception as e:
                if attempt == self.max_retries - 1:
                    # Return structured error for LLM to handle
                    return {
                        "success": False,
                        "error": str(e),
                        "suggestion": "Try a different approach"
                    }
                time.sleep(2 ** attempt)  # Exponential backoff

Agent Environment Setup Template

# agent_config.py — starter template for any enterprise agent

from langchain_openai import ChatOpenAI
from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain.memory import ConversationTokenBufferMemory
from langchain.tools import StructuredTool
from pydantic import BaseModel, Field
import os

# ---- CONFIGURATION ----
class AgentConfig:
    MODEL = "gpt-4o"
    TEMPERATURE = 0
    MAX_TOKENS = 4096
    MAX_ITERATIONS = 15
    MAX_EXECUTION_TIME = 120  # seconds
    MEMORY_TOKEN_LIMIT = 3000

# ---- LLM ----
llm = ChatOpenAI(
    model=AgentConfig.MODEL,
    temperature=AgentConfig.TEMPERATURE,
    max_tokens=AgentConfig.MAX_TOKENS,
    api_key=os.getenv("OPENAI_API_KEY")
)

# ---- MEMORY ----
memory = ConversationTokenBufferMemory(
    llm=llm,
    max_token_limit=AgentConfig.MEMORY_TOKEN_LIMIT,
    memory_key="chat_history",
    return_messages=True
)

# ---- TOOLS ---- (Define your tools here)
class SearchInput(BaseModel):
    query: str = Field(description="Search query string")

def my_search_tool(query: str) -> str:
    """Your search implementation."""
    return f"Results for: {query}"

tools = [
    StructuredTool.from_function(
        func=my_search_tool,
        name="web_search",
        description="Search the web for current information",
        args_schema=SearchInput,
    )
]

# ---- PROMPT ----
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful enterprise AI assistant."),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad"),
])

# ---- AGENT ----
agent = create_openai_tools_agent(llm, tools, prompt)

agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    memory=memory,
    verbose=True,
    max_iterations=AgentConfig.MAX_ITERATIONS,
    max_execution_time=AgentConfig.MAX_EXECUTION_TIME,
    handle_parsing_errors=True,
    return_intermediate_steps=True,
)

# ---- USAGE ----
if __name__ == "__main__":
    while True:
        user_input = input("\nYou: ")
        if user_input.lower() in ["exit", "quit"]:
            break
        result = agent_executor.invoke({"input": user_input})
        print(f"\nAgent: {result['output']}")
